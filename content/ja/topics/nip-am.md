**ステータス:** これは Buzz プロジェクト固有のドラフト提案です。NIP-AM は正式に採択された NIP ではありません。この名称は Buzz プロジェクトのドキュメントに由来するもので、公式の NIPs リポジトリが割り当てたり承認したりしたものではありません。

## 目的

NIP-AM は、AI エージェントのターンが完了するたびに、その使用量を記録します。エージェントはターンごとに `kind:44200` event を 1 件公開し、Buzz の慣例ではこれを通常の追記専用 event として扱います。content は NIP-44 で暗号化され、エージェントからオーナー宛てに送られます。中身はトークン使用量の数値と相関 ID で、コストの値が含まれる場合はいずれも推定値です。会話のトランスクリプトは含まれません。

## 制約

公開 tag によってオーナーとエージェントが識別されるうえ、relay は event が公開されたタイミングを引き続き把握できます。したがって、この形式はアクティビティが発生したという事実そのものを隠すわけではありません。使用量の値が欠けている場合、それは「不明」を意味し、決してゼロとして計上してはなりません。

## 委任閲覧者の提案

オープン中のドキュメント用プルリクエスト #8582 は、オーナーが署名する最小権限の付与（grant）を提案しています。この仕組みのもとでは、エージェントはアクティブな閲覧者ごとに個別の暗号化コピーを公開し、各コピーは厳密な grant event ID に紐付けられます。なお、このプルリクエストはランタイムの認可を一切変更しません。提案されている grant の kind `30180` と閲覧者数の上限はまだ検討中の論点であり、失効ポリシーも未確定です。失効によって relay 上の履歴や今後の読み取りを制限できる可能性はあります。しかし、閲覧者がすでに受け取ったコピーを消去することはできません。
