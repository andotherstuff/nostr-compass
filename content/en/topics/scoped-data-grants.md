Scoped Data Grants is an independent project proposal for signed capability grants that give access to scoped data. It uses event kinds 440 and 441. It is not an assigned official NIP.

The [latest revision](https://github.com/JAFairweather/nostr-scoped-data-grants/commit/6ea52227844909e45657d1bc5442b27dbafb0592) separates two concerns. One is the grant shape that an issuer must produce. The other is the set of rules a reader applies when it evaluates a grant. The revision also adds signed refusal fixtures and a local demo of issuing grants and attenuating them, meaning narrowing an existing grant. The project describes the work as reviewable. This commit does not show that any relay or client has adopted it.
