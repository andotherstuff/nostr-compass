## GREEN — new, source-backed stories

1. **Hubstr Blossom — 8/10; newly published infrastructure.** [Primary README and code](https://github.com/johninnis/hubstr-blossom). The GitHub repository was created September 24 (repository metadata); it has one initial commit and no tagged release shown. It is a self-hosted PHP Blossom server for Nostr media. Signed kind-24242 events authorize tenant writes; public reads serve content-hash-addressed blobs; SQLite tracks ownership; the README documents BUD-01/02/04/05/06/08/09/11/12, NIP-94 metadata, installation, and deployment. Its default mirror policy rejects private/reserved destination addresses and its image optimizer strips metadata from re-encoded images. **So what:** users can make their own origin serve the images and files referenced in Nostr posts, while other clients can fetch public media without credentials. [Nostr Recap #14](https://primal.net/e/b0a6d75e294a1bd14550db78dc348b1d8b82143aff78ac07917159e7badd4b3b) was the discovery lead, not the factual citation. Maturity limit: newly open-sourced implementation; no claim of broad production use.
2. **Meshstr — 8/10; experimental relay protocol and implementation.** [Primary README](https://gitlab.pocketlabs.dev/meshstr/meshstr/-/blob/main/README.md), [normative draft](https://gitlab.pocketlabs.dev/meshstr/meshstr/-/blob/main/nip/meshstr.md), [September 27 strfry integration commit](https://gitlab.pocketlabs.dev/meshstr/meshstr/-/commit/6d609fc99fa574b60c711619fe7ce391ff331d71), and [September 28 socket follow-up](https://gitlab.pocketlabs.dev/meshstr/meshstr/-/commit/9ad94be4c60547b222fa86a2cfe7ac4dc14b647b). A September 26 NIP-34 announcement surfaced the repository. Its alpha design has relay peers negotiate signed exposure budgets and issue signed usage receipts; an overrun can become independently checkable evidence. The repository includes a node/reference implementation, NIP-77 synchronization, and a strfry write-policy plugin/relay bridge. **So what:** relay operators could accept bounded, accountable traffic from unfamiliar peers without central content moderation decisions. Maturity limit: the project calls its specification a proposal and its sole implementation alpha; do not call this an adopted NIP or a deployed network. The GitLab repository predates this window (created September 2), while cited implementation commits are in-window.
