## Best additions beyond current drafts

1. **ContextVM transport correctness.** [PR #103](https://github.com/ContextVM/sdk/pull/103) deduplicates plaintext Nostr requests across relays and reconnects; its author reports that a non-idempotent tool had executed three times for one call. [PR #101](https://github.com/ContextVM/sdk/pull/101) confines resource updates to subscribed clients. Recommend a short SDK development paragraph, making clear that these are source merges, not a tagged release.
2. **Cyberspace's DECK-0003 specification catches up with its object implementation.** [PR #36](https://github.com/arkin0x/cyberspace/pull/36) adds parts and separately published hidden objects, [PR #38](https://github.com/arkin0x/cyberspace/pull/38) defines bag entries and encrypted referenced events, and [PR #40](https://github.com/arkin0x/cyberspace/pull/40) corrects an earlier claim that an `e` reference can preserve an old version of an addressable event. This is a direct follow-up to last week's Amethyst DECK-0003 implementation, not a new project launch. Cite the final corrected rule, not the superseded wording in #38.
3. **Wisp's NIP-22 reply behavior.** [PR #667](https://github.com/barrydeen/wisp/pull/667) publishes kind `1111` when replying to a kind `1111` comment and fixes reply tags and mixed-kind threading. [Wisp 1.2.5](https://github.com/barrydeen/wisp/releases/tag/v1.2.5) is in the fetch; frame this as a follow-up to last week's 1.2.4 relay-routing story after checking the release notes.
4. **Cambium's Nostr-based signer recovery.** [PR #22](https://github.com/forgesworn/cambium/pull/22) lets a phone scan a Sapwood invite and exchange encrypted enrollment over relays; [PR #18](https://github.com/forgesworn/cambium/pull/18) follows sealed relay-update announcements with a randomized connection delay to reduce timing correlation. The 0.5.0–0.7.1 release sequence needs collapsing into one story. Do not imply the unmerged companion Heartwood firmware path in #18 shipped.
5. **Coracle protected notes.** [PR #674](https://github.com/coracle-social/coracle/pull/674) adds an opt-in NIP-70 `-` tag to notes and replies. It merged September 22 and was absent from the September 23 issue. The PR explicitly did not test acceptance by an enforcing relay, so describe source support, not verified interoperable publishing.
6. **Cordn multi-device relay hints.** [PR #9](https://github.com/Cordn-msg/cordn/pull/9) adds coordinator relay locations to the replicated group document so a seeded device can find a non-default coordinator. This is new September 28 spec work beyond last week's Cordn offline-outbox release and this week's Amethyst Cordn integration.
7. **Bray NWC safety.** [PR #114](https://github.com/forgesworn/bray/pull/114) adds per-payment and daily caps, human confirmation where available, and isolated scoped wallet connections. It concerns Nostr Wallet Connect directly; bundle with its 3.5.x releases if release notes confirm the behavior, and avoid presenting the pre-announcement audit as a vulnerability disclosure.
